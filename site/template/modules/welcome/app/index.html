Welcome

This site is served by Fridolin. Each page is a module: a folder in the site's repository with a module.json that says who may open it.

How it grows

  1. Ask Fridolin for a new page — in the dashboard's Build page or, if a brain may build the site, over WhatsApp.
  2. It is built on a branch and you get a preview.
  3. You approve it in Fridolin's dashboard, and it goes live.

You can delete this module once the site has pages of its own.
